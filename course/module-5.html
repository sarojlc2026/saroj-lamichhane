PDF Remediation and Tagging

Why most course PDFs are unreadable, and the order of operations for fixing them.

Why this matters

The single most common barrier in higher education is a scanned PDF. To a screen reader it is a photograph of a page: no text, no structure, nothing. And these are often the required readings.

Learning objectives

By the end of this module you will be able to:

  • Distinguish a scanned image PDF from a tagged text PDF
  • Export accessible PDFs from Word and PowerPoint
  • Run OCR and correct the results
  • Understand when to stop remediating and find another source

The guide

If you fix only one category of file this term, make it your PDFs.

First, learn to tell the difference between the two kinds. Open the PDF and try to select a line of text with your cursor. If you can highlight individual words, it is a text PDF and there is something to work with. If your cursor draws a box across the whole page, it is a scanned image. A screen reader gets nothing from it at all, not badly formatted text, nothing.

The best fix is not to create the problem. When you make a PDF from Word or PowerPoint, do not print to PDF. Printing throws away all the structure you built. Instead use File, Export, Create PDF slash XPS, and before saving click Options and tick Document structure tags for accessibility. That preserves your headings, lists, table headers, alt text and reading order into the PDF.

If you have an existing scanned PDF, the order of operations is this.

Step one, ask whether you need the PDF at all. Very often the answer is no. Your library may have an accessible version. The publisher may offer an EPUB or HTML edition. If you scanned a chapter yourself, the original may exist digitally. Ten minutes asking a librarian frequently beats two hours remediating.

Step two, if you must remediate, run optical character recognition. In Acrobat Pro that is Scan and OCR, then Recognise Text. This converts the picture of text into actual text. It is imperfect. It will make errors, and it makes more errors on technical vocabulary, chemical names, and mathematical notation than on ordinary prose.

Step three, and this is the step people skip, proofread the OCR output. Use Edit PDF and read it. Chemical formulae, units and specialist terms are where OCR fails, and those are exactly the words that carry the meaning in a science course.

Step four, add tags. Acrobat's Accessibility tool has Autotag Document, which makes a reasonable first attempt. Then use the Reading Order tool to correct it: mark headings as headings, mark real tables as tables, mark decorative page furniture as background.

Step five, set the document title and language in Document Properties, then run the Accessibility Check and work through what it reports.

Now, some honesty about scope. A heavily formatted scanned PDF with multi-column layout, footnotes and tables can take hours to remediate properly, and the result is often still poor. There is a point at which the right decision is to find a different source or provide the content another way. Recognising that point is a skill, not a failure.

And if a student has an approved accommodation and needs the material now, contact your disability services office. Do not leave a student waiting while you learn Acrobat.

Step by step

  1. Test each PDF: can you select individual words?
  2. For new PDFs, export from Word using Create PDF/XPS with structure tags enabled, never print to PDF
  3. For scanned PDFs, first check whether an accessible version already exists
  4. Run OCR, then proofread the output, especially technical vocabulary
  5. Autotag, then correct headings, tables and background using the Reading Order tool
  6. Set document title and language
  7. Run the Accessibility Check and resolve findings

Checklist

  • No scanned image PDFs remain in required materials
  • PDFs exported from Office use structure tags
  • OCR output has been proofread
  • Tags, title and language are set
  • Accessibility Check passes

Practice task

Take your required readings and do the cursor test on each. Sort them into text and scanned. Deal with the scanned ones first, starting with anything students need in the first three weeks.
