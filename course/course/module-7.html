Structuring Your Course in the LMS

Module organisation, page structure, link text, and the settings that matter.

Why this matters

A course shell can contain perfectly accessible documents and still be unusable, because the student cannot find anything or cannot tell what a link leads to.

Learning objectives

By the end of this module you will be able to:

  • Structure LMS pages with correct heading levels
  • Write link and file names that make sense in a list
  • Organise modules predictably
  • Use the built-in accessibility checker in your LMS

The guide

Everything so far has been about individual files. This module is about the container, because a course full of accessible documents can still be an inaccessible course.

Start with heading levels inside pages, because this is the most common error in course shells and it is invisible unless you know to look. Your LMS page already has a title, and that title is almost always a Heading 1. So when you add content to that page and start with a Heading 1 of your own, you have created two document titles. Start at Heading 2 inside LMS pages. Every time.

Second, link text, and this matters more in an LMS than in a document because course pages are dense with links. Screen reader users pull up a list of links on the page and navigate from it. If that list reads click here, click here, this link, here, read more, the list is useless and the student has to go back and read the surrounding text for each one.

So write links that make sense alone. Week four reading, Ostrom on common pool resources, PDF. Submit the lab report. Course syllabus. Each of those tells a student what it is without any surrounding context.

Third, and related: name your files properly before you upload them. Final_v3_REVISED.docx tells a student nothing. Lab 4, Titration Procedure.docx tells them exactly what it is. Students download these into a folder and the filename is all they have.

Fourth, module organisation. Be predictable rather than clever. Use the same structure in every module: overview, readings, activity, assessment, in that order every week. Consistency is an accessibility feature, it is enormously helpful for students with attention or memory-related disabilities, and honestly for everyone. A student should never have to work out where you have put things this week.

Give modules and items descriptive names too. Module 4, Chemical Equilibrium beats Week 4. Students navigating by a list of module names should be able to find the equilibrium material without opening each one.

Fifth, avoid embedding content that traps keyboard users. Embedded documents, third-party widgets and interactive tools frequently cannot be reached or exited with a keyboard alone. Test it: put the mouse aside and tab through your page. If focus disappears, or you get stuck inside something and cannot tab out, that content needs a plain link alternative next to it.

Sixth, use the accessibility checker built into your editor. Canvas has one in the Rich Content Editor toolbar. It catches missing alt text, heading order problems, contrast issues and missing table headers, page by page. It is not comprehensive but it is right there and it takes seconds.

Finally, a course-level habit: write an accessibility statement in your syllabus telling students how to reach you and how to reach disability services if something is not working for them. It costs three sentences and it tells students you expect to be told.

Step by step

  1. Change page headings so content starts at Heading 2
  2. Rewrite link text so every link makes sense on its own
  3. Rename files descriptively before uploading
  4. Standardise module structure and use it every week
  5. Give modules and items descriptive names
  6. Tab through your pages with no mouse and fix anything that traps focus
  7. Run the LMS accessibility checker on each page
  8. Add an accessibility statement to your syllabus

Checklist

  • Page content starts at Heading 2
  • No vague link text anywhere
  • Files have descriptive names
  • Module structure is consistent week to week
  • Keyboard navigation works throughout
  • LMS checker passes on all pages
  • Syllabus has an accessibility statement

Practice task

Open your course as a student would see it and tab through one full module using only the keyboard. Note anywhere focus vanishes or gets stuck.
