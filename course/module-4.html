About this module

The scanned or untagged PDF is the most common barrier in higher education. This module covers tagging, reading order and table structure in Adobe Acrobat, and closes the course with guidance on using AI responsibly in course development.

What you will be able to do

By the end of this module you will be able to:

  • Set PDF document properties including title and language
  • Add and correct tags, and set reading order
  • Structure tables so they are navigable
  • Run the Adobe accessibility check and resolve findings

Before you watch. The module overview sets out the context and learning outcomes in one page.

  • Module 4 Overview (read on this page, or download the Word file)

What you need, and what to do if you do not have it. This module is taught in Adobe Acrobat Pro, which is the only tool that edits tags and reading order directly. Many institutions license it and many do not. Acrobat Reader will not do this work.

If you have no Acrobat Pro licence, you are not stuck. Two free routes cover the large majority of real cases:

  • Go back to the source. Nearly every inaccessible PDF in a course started as a Word or PowerPoint file. Fix the source using Module 2 or Module 3, then export with File, Export, Create PDF/XPS and document structure tags enabled. This produces a better result than remediating in Acrobat, and it costs nothing.
  • PAC, the free PDF Accessibility Checker from the PDF/UA Foundation, for Windows. It will not fix a file, but it will tell you accurately whether one is tagged and where the structure fails, which is enough to decide whether a file needs rebuilding.

Watch the module either way. Knowing what a tag tree is and why the cursor test matters is most of the value, and it applies whichever tool you end up using.

Read this before you remediate a single PDF. Fixing a PDF is the hardest and slowest accessibility work there is. It needs Acrobat Pro, it needs an understanding of tag trees and reading order, and on a badly built file it can take longer than rebuilding the document from scratch.

So the first question is never how to fix the PDF. It is "does this need to be a PDF at all?" Usually it does not.

  • Build the content as a page inside your LMS where you can. Canvas, D2L, Blackboard and Moodle pages are accessible by default if you use the heading tools, they reflow on a phone, and they need no remediation at all.
  • Post the Word or PowerPoint file instead of exporting to PDF. Students can open both, and the accessibility work you did in Module 2 or Module 3 survives intact.
  • Link to the source for journal articles and external readings rather than uploading a copy. A library link is someone else's accessibility obligation; a PDF you upload becomes yours.
  • Use PDF only when you genuinely need it: when layout must be preserved exactly, when the file must be printed as designed, or when it is a form.

When you do need one, produce it from a properly structured Word document using File, Export, Create PDF/XPS with document structure tags enabled. Never use Print to PDF, which discards structure entirely. This module teaches repair; Module 2 teaches prevention, and prevention is worth far more of your time.

00:00 [On-screen title: Module 4 Accessible PDF Documents]

Narrator: Welcome to Module 4 Accessible PDF Documents. In this video, you will learn how to make your PDF documents accessible to all learners.

00:13 [On-screen title: Document Title and Language]

In this section, we will set the PDF's document title and language.

[On-screen: An Adobe PDF file is open for demonstration]

As with Word and PowerPoint, PDFs need a descriptive title and language setting for accessibility. To set a document title in Adobe PDF, click Menu, then select Document Properties. Locate the Description section. Click on the space indicated to the right of Title.

Enter a descriptive title here, such as "Teaching Students About Self Efficacy." Click OK to apply your settings.

To set the document language, right-click on the document; select Document Properties. Click Advanced, and under Reading Options to the right of language, select English, and then click OK to apply your settings.

01:13 [On-screen title: Reading Order]

In this section, we will check the reading order in a PDF.

[On-screen: An Adobe PDF file is open, and the Reading Order panel is on the right, showing the numeric order of the content on Page 1.]

Reading order is important because it tells assistive technologies like screen readers what to read first, second, and so on. If the order is incorrect, the content may read out of sequence, making it confusing for learners.

To check reading order, open the Order panel from the right side panel. Expand the page to view the numbered items. '1' is the first item read by a screen reader, '2' is next, and so on.

You cannot edit reading order directly here, but you can fix it in the Tags panel.

01:58 [On-screen title: PDF Tags]

In this section, we will add tags to give the PDF a clear structure.

[On-screen: An Adobe PDF file is open with the Accessibility tags panel open on the right, showing the tags tree with tags such as <Document>, <Sect>, <H1>, <P>, <table>, <Figure>, and <L>.]

Tags are hidden labels that identify the structure of your document, such as headings, paragraphs, lists, tables, sections. These tags help assistive technology understand how the document is organized.

To view and edit tags, right-click on the side panel and make sure Tags is selected. Open the Tags panel. Expand the tags to see how each element is labeled.

[On-screen: The Tags panel on the right shows that the first heading of the document, Teaching Students About Self-Efficacy, is tagged as <P>.]

In this example, my headings are incorrectly tagged as paragraphs. Here is how to fix them.

Right-click the P tag. Select Properties. Under Type, change it to Heading Level 1 or the appropriate level. Repeat for all headings to ensure that they are correctly tagged.

03:21 [On-screen title: Alternative Text]

In this section, we will add alternative text to images.

[On-screen: An Adobe PDF file is open, showing an image on Page 2. The Accessibility tags panel is open on the right, with the Figure tag selected.]

Any meaningful image in your PDF should include alternative text that explain its purpose, not just what it looks like.

To begin adding alt text, right-click the Figure tag. Select Properties. Enter your description in the Alternative Text field.

An example of alternative text for this image would be "Smiling teacher sitting with the student working on a laptop showing collaboration and growth." Click Close.

04:03 [On-screen title: Accessibility Checker and Manual Review]

In this section, we will run the Accessibility Checker and do a quick manual review for accessibility.

[On-screen: An Adobe PDF file is open]

Let's identify any additional accessibility issues in our document. Go to All Tools, then Prepare for Accessibility, then Check for Accessibility. Make sure all options are selected; then click Start Checking.

[On-screen: The Accessibility Checker is open on the right.]

Review the results in the Accessibility Checker panel. Some items like reading order and color contrast always require manual review.

After checking manually, you can right-click and select Pass.

[On-screen: The file is saved by going to Menu and Save.]

Finally, save your document.

Key points

  • An untagged PDF is the most common barrier in higher education
  • Tags and reading order are what turn a PDF from a picture of a page into a document
  • Save after checking, the accessibility work is not stored until you do

Apply it to a real file

Open the practice file in Adobe Acrobat Pro. Use the Accessibility Checker together with the practices in the video to bring it up to standard while preserving the original content. If you do not have Acrobat Pro, read through the tasks anyway and see the note above on free alternatives.

Work on the practice file first if you like, but the version that matters is the one you do on your own course material. A skill practised only on someone else's document does not transfer.

Find and fix

  • document title and language
  • tag structure
  • reading order
  • alternative text, or marking images decorative
  • table formatting
  • list formatting
  • Download the Inaccessible.pdf practice file (PDF)

How to know you got it right

Do the Apply It on a PDF you actually assign, then verify in this order.

  1. The cursor test. Try to select a word with the text cursor. If you cannot, there is no text layer and nothing else matters until you run optical character recognition. This is the fastest and most important check in the whole course.
  2. Tags panel. Open the Tags navigation panel. You should see a tree of headings, paragraphs, lists and tables, not a single "No tags available" line and not a flat run of untagged content.
  3. Reading order. Use the Reading Order tool or the Order panel and confirm the sequence matches how a person would read the page. Multi-column layouts and text boxes are where this usually breaks.
  4. Document properties. Title filled in under Description, language set under Advanced.
  5. Accessibility check. Run it, resolve the findings, then save the file. The work is not stored until you do.

Where you can choose, do not remediate a PDF at all. Export a properly structured Word document with tags enabled and you will inherit most of this for free. Remediating in Acrobat is repair work; the Module 2 method is prevention.
