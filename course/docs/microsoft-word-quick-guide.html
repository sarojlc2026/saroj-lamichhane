Microsoft Word Quick Guide

Designing and Delivering Accessible Online Courses. Licensed CC BY 4.0.

Accessibility Inspection Panel Definitions

  • Errors: Identifies critical accessibility issues that must be fixed.

  • Warnings: Flags potential accessibility issues that require review.

  • Tips: Suggests best practices to improve usability. Below are the steps to begin review and remediation of Word documents.

Run Word’s Accessibility Checker

  1. Review > Check Accessibility.

  2. Review the Inspection Results pane.

  3. Address each issue listed.

  4. Recheck after correcting.

Document Title & Language

  1. File > Info > Properties > Title.

  2. Review > Language > Set Proofing Language.

  3. Select the correct language and click OK.

Apply Heading Styles

  1. Select your heading text.

  2. Home > Styles.

  3. Choose Heading 1, Heading 2, or Heading 3.

  4. Do not manually bold for headings.

  5. Do not skip heading levels (for example, do not skip from Heading 1 to Heading 3).

Set Proper List Formatting

  1. Select the items you want in a list.

  2. Home > Paragraph > Numbered or Bulleted List.

  3. Use Tab and Shift + Tab to create nested lists.

Add Alt Text to Images

  1. Right-click the image.

  2. Select Edit Alt Text.

  3. Enter a concise description of the meaningful content.

  4. If decorative, select “Mark as decorative.”

Create Accessible Tables

  1. Insert > Table.

  2. Select the header row.

  3. Table Design > Header Row.

  4. Avoid merged or split cells.

  5. Keep tables simple and only for data, not layout.

Ensure Color Contrast Is Clear

  1. Use dark text on a light background.

  2. Avoid using color alone to convey meaning.

Manual Check: Avoid relying on the accessibility checker alone. Manually verify title accuracy, alt text quality, and heading structure.

Confirm sufficient contrast for text, icons, and charts. - Use a contrast checker such as WebAIM’s Color Contrast Checker.
