Accessibility: Best Practices

Designing and Delivering Accessible Online Courses.

When creating course content, following the practices below will help you address accessibility efficiently and effectively.

  • When possible, build content directly in Canvas.

  • Limit Canvas uploads to Word and PPTX when possible.

  • Use pdf only when needed i.e. - the file size is more than 500MB.

  • The tables must have merged or empty cells maintaining layout of the document is imperative.

  • When converting from Word to PDF, use the “Save as” feature to preserve accessibility.

  • Avoid converting PowerPoints to PDF.

  • When possible link to outside resources such as journal articles. Uploading them as pdfs in Canvas will require you to ensure their accessibility.

  • Prioritize accessibility of frequently used documents.

  • When remediating, if possible, start with the original version of the document.

  • For Canvas Users: Use Canvas Studio for videos; it generates captions automatically which are ~85% accurate, so a review is still needed. You may contact your instructional design or media team to request captions.

  • Always use the built-in accessibility checker (in office 365 products, PDF and Canvas) and perform manual checks.

Note that an accessible word document does not always result in an accessible PDF.
