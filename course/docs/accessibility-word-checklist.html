Accessibility: Word Checklist

Designing and Delivering Accessible Online Courses. Licensed CC BY 4.0.

Designing and Delivering Accessible Online Courses. Licensed CC BY 4.0. While this is not an exhaustive list, it covers some of the most common accessibility issues to attend to while developing course materials. This list does not ensure WCAG compliance, it will, however, assist you in creating accessible content. Use this list as a starting point of your accessibility journey.

Headings

Reference: https://webaim.org/techniques/word/#intro

  • The document uses headings under styles to structure the content.

  • Headings are meaningful and accurately describe the content that follows

  • Headings are properly nested.

  • Heading levels are not skipped.

  • Tables are not used to format the content of document.

  • Alt text for tables convey tabular data in a descriptive form.

  • Each table has a header row specified.

  • Rows do not break across pages.

  • There are no empty or merged cells in the table.

  • Tables have a logical reading order from left to right and top to bottom.

Images

Reference: https://webaim.org/techniques/word/#altText

  • All images (charts, smart art) have alternative text.

  • Alt text does not start with “An image of”.

  • The alt text is contextual, descriptive, and clearly conveys the meaning of the image.

  • Images used for aesthetic purposes are marked as decorative.

  • Images of text are not used.

  • Hyperlinks use descriptive words to describe their purpose.

  • Non descriptive hyperlinks have a Screen Tip description.

Miscellaneous

  • File title, language and author under file info (or properties) is filled.

  • Sans serif fonts are used.

  • A contrast ratio of 4.5:1 for normal text and 3:1 for large text is maintained.

  • Bulleted/numbered lists are created with the templates under “Paragraph”.

  • Color alone is not used to convey meaning/information.

  • Clear and easy to understand language is used.

  • Headers and footers do not contain any crucial information.

Accessibility checker

Reference: https://webaim.org/techniques/word/#checker

Accessibility checker was used to fix all the errors and warnings.

A manual check was performed to check the title, language, alt text for all non-text visuals, table properties, hyperlink screen tips, and document navigation via keyboard.
